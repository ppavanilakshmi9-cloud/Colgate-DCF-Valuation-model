Colgate DCF Valuation Model
  ##Project Overview
    This project presents a complete Discounted Cash Flow(DCF) valuation model for Colgate-Palmolive built in Microsoft Excel.
    The model estimates the intrinsic value of the company using FCFF projections, WACC, Terminal Value, and Enterprise Value calculations.
